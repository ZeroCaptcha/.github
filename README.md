# ZeroCaptcha's .github repository

This repository holds what GitHub shows for the whole ZeroCaptcha organisation:

- [`profile/README.md`](profile/README.md), the organisation's profile page;
- the default [contributing guide](CONTRIBUTING.md), [security policy](SECURITY.md) and [issue templates](ISSUE_TEMPLATE/), which apply to every ZeroCaptcha repository that has none of its own.

The tests (`node --test`) check the profile's links.
